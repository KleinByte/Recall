# Sidebar League client assets

These navigation glyphs are normalized exports from Riot's League client files,
mirrored by CommunityDragon. Geometry is preserved and flat fills are normalized
to the Recall metal color so the set remains legible in both sidebar states.

- `dashboard.svg`: `rcp-fe-lol-static-assets/nav-icon-profile.svg`
- `live.svg`: `rcp-fe-lol-postgame/scoreboard-kda-icon.svg`
- `review.svg`: `rcp-fe-lol-postgame/scoreboard-stat-switcher-eye.svg`
- `matches.svg`: `rcp-fe-lol-postgame/clock-icon.svg`
- `skill.svg`: `rcp-fe-lol-postgame/icon-mastery.svg`
- `progress.svg`: `rcp-fe-lol-static-assets/ranked-widget/ranked-progression-icon-aegis.svg`
- `champions.svg`: `rcp-fe-lol-static-assets/nav-icon-collections.svg`
- `challenges.svg`: `rcp-fe-lol-postgame/scoreboard-challenge-crystal-icon.svg`
- `settings.svg`: purpose-built flat cog glyph for clarity at navigation size

League of Legends and these client assets are property of Riot Games.
