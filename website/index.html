The big additions

Review more than a scoreboard.

The latest work is focused on the part that usually disappears after a match: where players were, how the early route came together, and what you should carry into the next game.

Local computer vision

Recall reads the minimap you can already see.

Recall uses a state-of-the-art local vision pipeline to fill in the moments between Riot’s periodic timeline snapshots. While a supported match is running, it turns visible minimap pixels into timestamped champion sightings, jungle-camp state, route splits, and confidence-tagged evidence for review.

Fair play by design

If League has not drawn a champion because they are hidden by fog of war, there are no pixels for Recall to detect. It does not read League process memory, inject code, intercept packets, automate input, or reveal information the player could not already see.

It is built to help you review your own game afterward—not to make decisions for you during it.

Jungle clear review

See the opening route and every recorded split.

When Recall identifies that you jungled, the match gets its own Jungle clear tab. It shows the observed route on the full map, each detected camp time, the evidence source, and how confident the attribution was.

How Recall defines a full clear 6 unique non-river camps before 8:00

Partial routes remain in that match’s review, but they do not change your average, fastest, or longest full-clear stats.

02

Match playback

Then scrub through the whole game on one shared clock.

Playback lines up team gold, kills, items, levels, objectives, jungle clears, and champion movement. Riot timeline snapshots and visible-minimap observations can appear together, so the match has more detail without pretending every point is equally certain.

  • Evidence is labeled. Observed CV, Riot snapshots, reconstructed points, and estimates use different treatments.
  • Gaps stay gaps. Recall does not draw a route through time it did not observe.
  • Everything stays aligned. Click a fight, objective, camp clear, or timeline marker to move the map to the same moment.

During the game

Keep the useful live context on a second screen—or just keep the dial.

The in-game page keeps the visible scoreboard, estimated team resources, recent events, and Recall’s live Tempo read together. If the full panel is more than you want, the small draggable Tempo overlay can stay above the game and become click-through when you lock it.

  • Resource totals are clearly estimates. Riot does not expose exact team gold during play.
  • Tempo reacts to the last stretch of the game. Fights, objectives, sprees, and lead changes move the gauge.
  • Multikills have their own sequence. Double, Triple, Quadra, and Pentakill each push the core into a stronger state before it cools down.

Honest about the evidence

Playback is a review aid, not hidden game data.

Riot timeline data is periodic. Minimap tracking can add observations while Recall is running, minimap tracking is enabled, and the supported in-game map is visible. Fog of war, occlusion, UI changes, and low confidence can still leave gaps.

  • Observed

    A position was supported by minimap pixels at that time.

  • Snapshot

    The position came from an exact Riot timeline frame.

  • Estimated

    Recall is showing a bounded reconstruction or movement between known evidence.

  • Unknown

    No credible path is drawn when the evidence does not support one.

Good to know

Questions before you install.

Recall is an independent, source-available Windows companion for the locally running League client.

What does Recall need from my Riot account?+

Recall connects to the League client you already signed into. It never asks for your Riot password. Your Riot ID and PUUID are used locally to identify your rows in match, challenge, mastery, and ranked data.

Should I add a Riot API key?+

Yes, at least for the first history import. Recall works without one, but the local League client only exposes its latest 20 games across all modes. A development key lets Recall scan every Match-V5 page Riot currently makes available, save those games locally, and resume around Riot’s rate limits. Riot development keys expire every 24 hours, so you may need to generate a fresh one if the import takes longer.

What still works without a Riot API key?+

Recent match syncing, complete recent scoreboards, grades, supported League-client timelines, challenges, live capture, Tempo, and minimap tracking do not need a developer key. The key is only used for the history import you start from Settings and is protected with your operating system’s secure storage.

Can Recall import every match I have ever played?+

Recall imports every Match-V5 page Riot returns; that is deeper than the League client’s latest 20 games, but it is not a promise of an account’s entire lifetime. Rotating modes are not always exposed consistently, and Riot availability and rate limits still apply. Once Recall has a match, it keeps it in your local archive.

How accurate is match playback?+

Riot timeline frames provide exact periodic snapshots, usually around one minute apart. When Recall was running during the game, minimap tracking can add more frequent observations. The player shows whether a point was observed, a Riot snapshot, reconstructed, or estimated; it leaves unsupported gaps unknown instead of drawing a made-up route.

What does minimap tracking capture?+

On supported Summoner’s Rift games, Recall samples the visible minimap—not the whole game view—to look for champion icons and jungle-camp state. Capture is local, can be turned off in Settings, and automatically stops when the match ends. Fog of war, overlapping icons, UI changes, occlusion, and low-confidence frames can still leave gaps.

Does computer vision reveal fog of war or play the game for me?+

No. Recall can only analyze pixels League has already drawn on your visible minimap. A champion hidden by fog of war gives it nothing to detect. Recall does not read League process memory, inject code, intercept packets, automate input, or tell you what action to take; it records evidence for your own review. That design follows the fair-play boundaries in Riot’s Developer General Policies and avoids the unauthorized-program behavior described in Riot’s Terms of Service. Recall is independent and is not endorsed by Riot.

Why is there no Jungle clear tab on some games?+

The tab appears when Recall resolves you as the jungler and has usable minimap telemetry for that game. A full clear means six unique non-river camps before 8:00. Partial routes remain in the match review but do not affect a champion’s average, fastest, or longest full-clear stats.

What are Recall Score and RVI actually measuring?+

Recall Score grades one complete match against a frozen comparison built from similar games in your own local history. Summoner’s Rift can use Combat, Survival, Utility, Economy, Macro, Vision, and Initiative; ARAM uses the four arms that fit that mode. Career RVI averages its available career arms and adds Range for consistency and breadth. Lobby percentile is shown separately and does not set the Grade.

Does Recall upload my match archive?+

No. Matches, timelines, minimap telemetry, notes, tags, experiments, settings, and backups stay on your PC. Recall has no account service and does not build an analytics profile from how you use it. Requests to Riot and GitHub only happen for the features that need them, such as syncing, a history import, game assets, and update checks.

Is the Windows installer signed?+

Yes. Recall’s published Windows installer is Authenticode-signed and timestamped under Jordyn Kleinheksel with a Microsoft ID Verified certificate. You can also inspect the linked VirusTotal report before downloading.

Why can SmartScreen still call a signed app “unrecognized”?+

Code signing proves who published the file and that it was not changed after signing. SmartScreen also uses publisher and file-download reputation. Recall’s signing identity is new and does not have enough install history yet, so Windows may still warn even though the signature is valid. Check the publisher and hash before choosing to run any download.

Is Recall open source?+

Recall is source-available under the PolyForm Noncommercial License 1.0.0. The repository is public for review and permitted noncommercial use, but that license is not OSI-approved open source.

Which queues and versions of Windows are supported?+

Recall supports Windows 10 and 11. It keeps Ranked Solo/Duo, Ranked Flex, Normal, Quickplay, Swiftplay, ARAM, ARAM: Mayhem, and League Classic separate so their pace, items, grades, and history are not mixed together.
