Good to know

Questions before queue.

Recall is an independent, open-source companion built for Windows and the locally running League client.

Does Recall need my Riot password?+

No. Recall connects to the League client already running on your PC. It never asks for or stores your Riot password.

Do I need a Riot API key?+

No key is needed for normal syncing, complete recent scoreboards, live capture, grades, or recent timelines. A personal Riot API key is optional for deeper Match-V5 history imports.

Which game modes are supported?+

Recall treats Ranked Solo/Duo, Ranked Flex, Normal, Quickplay, Swiftplay, ARAM, ARAM: Mayhem, and League Classic as distinct modes.

Why does Windows show a SmartScreen warning?+

The installer is not currently code-signed. Recall is open source, and the same public repository builds every GitHub release.

Can Recall recover games from months ago?+

The local League client exposes only its recent window. Recall permanently saves games it sees. An optional Riot API key can import deeper supported Match-V5 history, subject to Riot’s availability and rate limits.
